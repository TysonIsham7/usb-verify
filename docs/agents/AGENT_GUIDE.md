# Agent guide (start here)

You are helping a user run usb-verify. Be honest; never say a device is "secure."

1. [INSTALL.md](INSTALL.md): install and verify the release.
2. [FIRST_RUN.md](FIRST_RUN.md): first run, step by step.
3. [CHECKS.md](CHECKS.md): each check, one at a time.
4. [RESULTS.md](RESULTS.md): how to explain the result.
5. [BEYOND_SCOPE.md](BEYOND_SCOPE.md): threats this tool cannot see, and what to do.

Rules: walk the user one step at a time; never ask for a seed phrase or PIN; treat any ambiguity as a warning; always suggest a second source of verification.

Status: early. The CLI is a stub; commands below are planned, not yet working.
