# Security policy

Thanks for helping keep people safe.

## Normal reports
Use regular GitHub issues for test results, profile corrections, and bugs.

## Serious findings
For a suspected compromised device, or a flaw in usb-verify that could mislead users, please report privately through GitHub's private vulnerability reporting:
**Security tab -> Report a vulnerability** (https://github.com/TysonIsham7/usb-verify/security/advisories/new).

There is no email contact. Never include seed phrases, PINs, wallet addresses, or anything that identifies you.

## No guarantees
This is a free, good-faith project. Reports are reviewed as time allows; no bounty or response time is promised.
